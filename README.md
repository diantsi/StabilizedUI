iOS Swift Package designed for real-time User Interface stabilization against external vibrations and physiological hand tremors. Powered by **CoreMotion** sensor fusion and low-level **Metal API** GPU hardware acceleration.

## Tech Stack

* **Language:** Swift
* **Graphics & Rendering:** Metal API, MetalKit, Core Graphics, DisplayLink
* **UI Frameworks:** SwiftUI, UIKit, ImageRenderer
* **Sensors & Math:** CoreMotion, SIMD, Quaternions
